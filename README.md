# Κατανομή ΓΡ

Εφαρμογή που μοιράζει ΓΡ στο ωρολόγιο πρόγραμμα του σχολείου (αρχείο Excel).

- Κάθε εκπαιδευτικός παίρνει 1 ΓΡ την εβδομάδα. 0 = εξαίρεση, 2+ = επιβάρυνση.
- Κανόνες: όχι στην 7η ώρα, το πολύ ένα τη μέρα, μόνο σε μέρα με μάθημα, προαιρετικά μόνο σε κενό ανάμεσα σε μαθήματα.
- Αποθηκεύει το Excel με τα ΓΡ και στατιστικά έξω από την περιοχή εκτύπωσης.
- Το αρχείο επεξεργάζεται μόνο στη συσκευή σου και δεν ανεβαίνει πουθενά.
- Ανοίγει από υπολογιστή και κινητό και μπορεί να εγκατασταθεί ως εφαρμογή.
